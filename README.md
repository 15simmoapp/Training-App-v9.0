# Matthew's Training App V9 Complete

This package is ready for GitHub Pages. It includes:

- 36 local exercise and progression images
- Expanded Legs, Push and Pull exercise library
- Growth, Sustainability and Athleticism prescriptions
- Set-by-set tracking, multiple load units, extra sets and swaps
- Rest timer and safe tap-out
- Speed bag challenges with verified external video links
- Illustrated calisthenics pathways
- Local storage and progress chart
- Light and dark modes

## Upload
Upload the contents of this folder to the root of a public GitHub repository. Enable GitHub Pages from `main` and `/(root)`.
